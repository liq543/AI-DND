# Reusable painted map assets

Generated with the built-in ImageGen tool on 2026-10-07. These are campaign-agnostic material and foliage atlases, not gameplay state. The PNG files preserve the selected originals. The WebP files are 512 × 512 runtime copies made by format conversion and downsampling; the canopy alpha is preserved.

`engine/illustration.py` embeds each atlas once in a cached SVG definition and reuses its quadrants. Map generation calls no image service, needs no credentials, and remains deterministic and offline. Procedural SVG supplies geometry, fog, labels and uncatalogued fallbacks. Painted portraits, equipment and object cells supply the main character and furnishing art. Terrain art does not alter the tactical grid or consume the rules RNG.

## Final prompts

### forest-canopies.png / forest-canopies.webp

Use case: stylized-concept. Asset type: production game sprite sheet for a fantasy top-down tactical tabletop. Create one square atlas containing EXACTLY FOUR isolated mature deciduous tree canopy sprites, in a precise equal 2 by 2 arrangement, each centered in its own quadrant with generous transparent padding (minimum 12% around each sprite). Orthographic directly overhead view, ZERO side-view trunk, no ground plane, no landscape, no labels or text or gridlines. Four varied oak / beech / mixed broadleaf canopies: dense dark oak, airy olive beech, irregular moss-green oak, smaller pale sage canopy. Rich hand-painted realistic fantasy battlemap illustration, hundreds of tiny individual leaves, branches subtly visible in gaps, naturally jagged irregular edges, overlapping masses of leaves with strong dimensionality, sophisticated muted forest greens and moss olive with subtle golden highlights. Directional soft sunlight from upper left, warm ochre leaf tips, deep cool green shadow recesses at bottom right, subtle tight transparent contact shadow beneath each canopy. Every sprite fully isolated on actual transparent alpha with no opaque background or checkered pattern. Assets must remain readable when shrunk to 48 pixel diameter. Not cartoon spheres, not low-poly or vector, not circular balls, no flower pots. The sprites should look like painted terrain from a premium fantasy RPG map.

## Expanded library

The same built-in ImageGen workflow produced 15 additional atlases: **180 cells**, including **80 portrait bases**, **64 furniture/prop/fitting sprites**, **12 fallen-body sprites**, **16 equipment illustrations**, and **8 structural/floor materials**. Together with the original 12 terrain/canopy cells, the library contains 192 cells.

Portraits use 256px WebP cells; object sprites use 160px, bodies 192px, equipment and surfaces 256px. Transparent alpha is preserved. `tools/build_art_assets.py` only splits the equal atlas cells, trims alpha padding, resizes and converts to WebP. The PNG originals are retained unchanged. Runtime art uses local assets and deterministic appearance-based selection with no image API calls. Custom public portraits retain precedence. Finite bases cannot represent every possible facial trait exactly.

The final prompts for this expansion are in [expanded-prompts.json](expanded-prompts.json); the first two are explicitly marked as reconstructed normalized records. All other expanded prompts are the exact generation prompts. Source PNGs are beside this document; each similarly named directory contains its cropped runtime cells. Common furniture definitions are embedded once per map, and unused surface images are omitted.

## First-pass visual verification

The independent critic rated the expanded visual overhaul **8.4/10**, with no blocker to the requested 8/10 threshold. The review included connected active maps and room details, generic interiors and outdoor maps, portraits, tokens, corpse identities, condition badges, fog, lighting, weather and a captured spell effect. Campaign-specific screenshots and timings remain in the active campaign log; generic review evidence is in `artifacts/visual-review`.

Final regression run: **204 tests passed**. Recorded active map assembly medians were approximately 8–28ms, worst cold sample 53ms. Eight local browser scene-load samples, including decoding used images and two animation frames, were 69–145ms. A 120-frame forest/storm sample had median/p95 intervals 16.70/16.80ms. These are observed local measurements, not device-independent performance promises. Review-only instrumentation lives in the gallery, not the production viewer.

Known refinements: finite portrait bases approximate uncatalogued traits; several small objects retain immediate SVG fallbacks; deep-water boundaries and regional coasts can be further softened. These are cosmetic and do not alter tactical cells or engine state.

## Complete map and interior expansion

The second pass adds **148 cells across 13 atlases**, bringing the reusable library to **340 cells**. These include tables and beds, storage, workspaces, rugs and décor, structural details, small props, outdoor objects, regional landmarks, roofing, walls, foliage, street paving, and empty surfaces for continuous furniture. The existing 80 portrait bases and 12 fallen-body illustrations remain part of this consistent painted library.

The exact generation prompts are retained in `all-map-prompts.json`, `wall-materials-prompt.json`, `foliage-details-prompt.json`, `final-material-prompts.json`, and `continuous-cleanup-prompt.json`. Original PNGs are retained. Object cells use 192px WebP; materials use 256px. `interior-tables-crops.json` and `continuous-furniture-crops.json` document source cropping. Preparation only crops, trims faint alpha padding, resizes and converts formats; it does not paint replacements.

The shared theme uses an overhead view, muted olive and umber, aged limestone, warm walnut, restrained brass and burgundy, and consistent soft light. Continuous counters, tables, pews and shelves fit actual tile runs, using empty surfaces so dishes and decorations are not stretched. Beds and individual furnishings retain distinct silhouettes. Roof planes, hips, caps and eaves remain clipped to actual building cells; textured wall treatments preserve existing footprints. Leafy hedge edges, painted bridge decking and street materials apply throughout the same renderer.

Weather exposure distinguishes sheltered floors and indoor pools from outside ground and connected rivers. Fog still suppresses unseen entities. Cold hearths do not produce flames or light; actual burning props illuminate dim rooms. Corpses use fallen-body art with compact identity labels, while unconscious and petrified creatures have distinct states. None of these rendering changes writes mechanics or consumes the rules RNG.

The complete static-map audit reviewed **33 active maps**, with an overview and four enlarged sections per map: **165 final screenshots**. Each map independently reached **8.0/10 or higher**, with scores ranging from 8.0 to 8.4. The map-by-map report and campaign-specific evidence remain in the active campaign's own log. Generic fog, bodies, weather and portrait studies are in `artifacts/visual-review`. Static ratings do not establish animation frame rates.

Final isolated regression: **217 tests passed**. On the local machine, warm assembly medians across the 33 maps were **2.27–71.26ms**, worst cold assembly **83.77ms**. Warm browser map loads, including used-image decoding and two animation frames, measured **47–499ms**; an earlier first uncached regional load took 2220ms. A 120-frame storm study recorded median/p95 intervals **16.70/16.80ms**. These are local observations under concurrent workload, not universal performance guarantees. Runtime generation remains deterministic, offline and cached, with no image-service call.

## Identity and fallen-body expansion

The identity catalogue adds **180 active corpse sprites** and **116 portrait bases**, replacing selection from the earlier 12 generic bodies. Humans have four skin families and four clothing groups for masculine, feminine and neutral presentation. Eight playable fantasy species and eight humanoid monster species have compatible gendered and neutral bodies; coloured Dragonborn, Tieflings and dark Elves have additional matching faces and bodies. Animals, dragons, undead and constructs have their own anatomy. Maned lions and antlered deer are restricted to masculine presentation; lioness/doe and neutral variants have compatible faces and bodies.

The retained art library contains **636 cells**, including the 12 legacy body illustrations; the active corpse catalogue uses the 180 new cells. New runtime bodies use 192px WebP, portraits 256px; the 296 new active assets occupy approximately **4.1 MB**. Sources are retained unchanged. Exact prompts and source records are in `identity-v3-prompts.json`, `identity-v3-additional-prompts.json`, `identity-v4-repairs.json`, `identity-final-prompts.json`, `identity-cell-repairs.json` and `identity-extra-cell-repairs.json`. Earlier corpse-v3 extractions were rejected for clipping and are not referenced by the catalogue. Reviewed crop rectangles correct uneven atlas spacing. Fourteen individual ImageGen repairs remove neighbouring fragments and matte fringes; their originals are in `cell-repairs/`. Preparation only crops, trims alpha bounds, resizes and converts formats.

Portraits, map faces, corpses and anatomical fallbacks share one resolved visual identity. Species and presentation are hard selection boundaries; explicit pins precede preserved likeness, structured identity and public description. Unsupported anatomy never falls through to nickname art. Skin/outfit rank only compatible bodies, using the selected portrait's actual base. Copied likeness preserves the selected face through storage and character conversion. Unknown presentation uses neutral art. Finite assets approximate individual facial features; a custom pinned portrait still requires manual visual verification.

The DM's read-only `asset identity [ids...]` helper reports selected face/body assets and missing or conflicting identity; `--all --issues-only` audits all creatures. Known visual facts can be pinned through `asset look <id> --species Elf --presentation female`; these do not change mechanical species or stats. The active campaign audit is stored with that campaign's own notes. Missing facts are reported, never guessed from clothing.

The independent identity-art review inspected all **180 new body cells**, **116 new portrait cells** and **55 browser screenshots** covering eleven paired living/dead studies and four enlarged sections each. Final results are in `artifacts/visual-review/identity-critic.md`. The static visual score reached **8.2/10**. Final isolated regression: **235 tests passed**. Eleven local browser loads, including image decoding and two frames, measured **86–234ms**; warm map assembly medians were **7.48–52.67ms**, worst cold sample **89.92ms**. These fixture timings were observed under concurrent workload and do not establish frame rates or performance on every device. No image service or rules RNG is used during rendering.
